# 追加するとよい LP（ランディングページ）案と試作（2026-11-12）

LP は「1つの目的のためだけのページ」です。広告・Instagram・メルマガ・チラシの QR コードから直接開いてもらい、迷わず申し込んでもらうために使います。

| LP | プレビュー | 目的・使う場面 |
|---|---|---|
| ① お試しセット LP | https://wakabafarm.com/pages/about?preview_theme_id=195942744432&view=lp-trial | 新しいお客さまの獲得。Instagram 広告、Google 広告、チラシの QR コードからの入口 |
| ② 人参ジュース ギフト LP | https://wakabafarm.com/pages/about?preview_theme_id=195942744432&view=lp-juice-gift | 母の日・父の日・お中元・お歳暮。旧サイトのブログでも毎年ギフトを案内していた |
| ③ 自然農法のお米 LP | https://wakabafarm.com/pages/about?preview_theme_id=195942744432&view=lp-rice | 新米の季節。「田んぼの年数で選べる」という珍しさを伝える |

- どれも、同じ汎用セクション「若葉農園 LP」（`sections/wakaba-lp.liquid`）のブロックを並べ替えて作っています。
- ブロックは11種類：ファーストビュー／選ばれる理由／写真と文章／商品／比較表／成分検査／流れ／お客さまの声／よくある質問／お知らせ枠／申し込み（締め）。
- テーマエディタで、文言・写真・商品をそのまま差し替えられます。新しい LP も同じ部品で作れます。
- 共通の工夫：
  - スマホでは、申し込みボタンが見えないときだけ画面下にボタンを出す。
  - よくある質問は、Google 向けの構造化データとしても出力する。
  - 価格は Shopify の商品から自動で表示する。
- 文章は旧サイトの事実だけで書いています。お客さまの声も、旧サイトに載っていた会員さまの声です。

### ① お試しセット LP の構成
ファーストビュー（価格・申込ボタン）→ 選ばれる理由3つ → 成分検査 → 「肥料なしで本当に育つの？」→ 会員さまの声6件 → お届けまでの流れ → よくある質問5問 → 申し込み

### ② 人参ジュース ギフト LP の構成
ファーストビュー（原材料は人参とすだちだけ）→ 贈りものに選ばれる理由3つ → 種から育てた人参の話 → ギフトセット7種 → 商品について（原材料・内容量）→ よくある質問 → 申し込み

### ③ お米 LP の構成
ファーストビュー → お米のこと3つ（肥料・農薬不使用／田んぼの年数で選べる／無酸素パック）→ 6商品 → お1人さま8パックまでのお知らせ → 水田約400a・有機率100％ → よくある質問 → 申し込み

## 公開するときの手順
1. Shopify 管理画面で新しいページを作る（例：タイトル「お試しセット」、URL `/pages/otameshi`）。
2. そのページの「テンプレート」で `lp-trial` を選ぶ。
3. テーマを公開する（または、使っているテーマに同じテンプレートを入れる）。

## 1回目：検索まわりと中身
| 見つけたこと | 対応 |
|---|---|
| 固定ページ・商品・記事の説明文が、本文の先頭320字そのまま（途中で切れる） | 固定ページ・LP・お問い合わせ・お試しセット・人参ジュースに、専用のタイトルと説明文（70〜95字）を設定 |
| ブログの名前が「ニュース」で、メニューの「畑だより」と食い違う | ブログ名を「畑だより」に変更。説明文も設定（URLはそのまま） |
| コレクションに説明がない | 4つのコレクションに説明文と、検索用のタイトル・説明文を設定 |
| ご利用ガイドに「カードは使用できません」「代金引換」と古い記述 | 「ご注文手続きの画面に表示される方法からお選びいただけます」に書き換え（ガイド・定期宅配） |
| ブラウンサイダーの検索用説明文が「黒糖」、本文は「糖蜜」 | 説明文を本文に合わせて「糖蜜」に修正 |
| 人参ジュースの商品名に全角スペース | 「プレミアム人参ジュース 350ml／1,000ml」に統一 |
| お試しセット（常温便）の説明が1段落に詰め込まれて読みにくい | 見出しと箇条書きに整理（文言はそのまま） |

# 旧サイトの SEO（検索順位）を新サイトへ引き継ぐ方法

## 結論

**大部分は引き継げます。** Google の順位は「URL」と「ドメイン」に付いています。そのため、旧URLにアクセスした人と Google を、新しいページへ **301リダイレクト**（恒久的な転送）で案内すれば、順位はほぼ新URLへ移ります。

- 切り替えから数週間〜2か月ほどは、順位が一時的に下がることがよくあります。
- 移行しない記事のように、行き先が同じ内容のページでない場合、その記事の順位は引き継がれません。

## 旧サイトの現状（調査結果）

| 項目 | 内容 |
|---|---|
| ドメイン | `www.wakaba.jpn.com`（Shopify は `wakabafarm.com`）← **ドメインが違うことが一番の課題** |
| SEOプラグイン | なし。meta description は全ページで未設定。canonical と robots はWordPressの標準設定 |
| ページタイトル | `ページ名 \| 自然農法 若葉農園`（トップは「自然農法 若葉農園 \| 若葉農園の自然農法は…」） |

| カテゴリURL | `/archives/topiccat/farm/` など7種類 |

## 作ったもの

- `data/seo/redirects_shopify_import.csv`：Shopify にそのまま取り込める旧URL→新URLの表（1,527件）
- `data/seo/redirects_map_detail.csv`：種類とメモ付きの確認用（Excelで開けます）
- `scripts/build_redirects.py`：上の2つを作るスクリプト。記事を追加で移行したら、ここを直して作り直します

## 決めていただくこと：ドメインをどうするか

リダイレクトは、**旧ドメインへのアクセスが Shopify に届いて初めて**効きます。方法は3つあります。

1. **wakaba.jpn.com を Shopify に接続する（おすすめ）**
   - DNS の `www`（と必要なら `@`）を Shopify に向けます。Shopify が wakabafarm.com へ転送し、そのあと上のリダイレクト表が働きます。
   - WordPress サーバーは止められます。
   - メールに使う MX レコードは触りません。
2. **WordPress のサーバーを残し、.htaccess で wakabafarm.com へ 301 転送する**
   - サーバー代がかかり続けます。
3. **wakaba.jpn.com を Shopify のメインドメインにする**
   - ドメインが変わらないので、旧サイトの順位は一番残りやすい方法です。
   - そのかわり、すでに wakabafarm.com で付いている順位や広告・SNSのリンクは転送になります。
   - どちらのドメインの検索流入が多いかは、Search Console で確認して決めるのが確実です。

## 切り替え当日の手順

1. リダイレクト表を Shopify に取り込む。
   - 管理画面：オンラインストア → ナビゲーション → URLリダイレクト → インポート
   - API でも取り込めます。
2. 上で決めた方法で、旧ドメインを転送する。
3. Google Search Console の作業：
   - 新ドメインを登録し、`https://wakabafarm.com/sitemap.xml` を送信する。
   - 旧ドメインのプロパティで「アドレス変更ツール」を使う（方法1・2の場合）。
4. 旧URLを10件ほど開き、正しいページへ転送されるか確認する。
5. 2〜8週間、Search Console で順位と「404エラー」を確認する。

## あわせてやると効果が上がること

- **未移行の371記事のうち、検索から人が来ている記事だけでも移行する。** Search Console の「ページ」レポートで、表示回数が多い記事を確認できます。
- 固定ページと商品に、SEO用のタイトルと説明文を入れる。旧サイトは未設定だったので、ここは新サイトでかえって良くなる部分です。
- トップページのタイトルに「自然農法」を残す（オンラインストア → 各種設定）。

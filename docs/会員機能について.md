# Shopify で会員向けページ・会員機能は作れるか

**結論：作れます。** 標準の「顧客アカウント」機能に加えて、テーマを少しカスタマイズすれば
「会員だけが見られるページ」も作れます。アプリを使えば、より細かい公開制御やポイント制度も追加できます。

## 1. 標準機能でできること（追加費用なし）

| 機能 | 内容 |
| --- | --- |
| 会員登録・ログイン | Shopify の顧客アカウント。新しい顧客アカウントでは **パスワード不要**（メールに届く6桁コードでログイン） |
| マイページ | 注文履歴、配送状況、住所の登録・変更、再注文 |
| 定期便の管理 | 定期購入アプリ（Shopify Subscriptions 等）を入れると、マイページから定期便のスキップ・停止・変更ができる |
| 会員の分類 | 顧客に「タグ」（例：`定期会員` `研修生` `卸`）を付けて分類。**Shopify Flow**（無料）で「定期便を申し込んだら自動でタグ付け」も可能 |
| 会員限定の割引 | 割引を特定の顧客・顧客セグメント（タグ等で絞り込み）だけに適用 |

## 2. 「会員だけが見られるページ」の作り方

### A. テーマのカスタマイズ（おすすめ・追加費用なし）
Shopify のページテンプレートに次のような条件を入れ、ログイン中の会員、または特定タグの会員にだけ本文を表示します。
非会員には「ログインしてください」と案内を出します。

```liquid
{% if customer and customer.tags contains '定期会員' %}
  {{ page.content }}   <!-- 会員向けの本文 -->
{% elsif customer %}
  <p>このページは定期宅配会員さま専用です。</p>
{% else %}
  <a href="{{ routes.account_login_url }}">ログインしてご覧ください</a>
{% endif %}
```

想定される使い方：定期会員さま向けのお知らせ・今週のお野菜・レシピ、会員限定の商品、研修生向けの資料 など。

### B. アプリを使う
Locksmith などの公開制限アプリを使うと、ページ・商品・コレクション単位でコードを書かずに公開範囲を設定できます（有料のものが多い）。

### C. マイページ内に独自ページを作る（開発が必要）
「お気に入り」「ポイント」「会員証」などのページを、マイページの中に独自に追加できます（customer account の full-page extension）。
アプリを開発する必要があるため、A・B で足りなければ検討します。

## 3. 旧サイト（Welcart）の会員からの移行

- Welcart の会員一覧を CSV で出力 → Shopify の「顧客」に CSV でインポート（氏名・メール・住所・電話・タグ）。
- **パスワードは移行できません。** ただし Shopify の新しい顧客アカウントはメールのコードでログインするため、会員さまに「パスワードを設定し直してください」と案内する必要はありません。
- メールマガジン配信の同意（マーケティング許可）は、同意を取っている方だけ「許可」にしてインポートします。
- 旧サイトの会員ポイント（Welcart のポイント機能）を使っていた場合、Shopify には標準のポイント機能がないため、ポイントアプリで残高を引き継ぎます。

## 4. 定期宅配（会員制の中心）について注意点

旧サイトの定期宅配は「フォームで申込 → 郵便局の自動振込」で運用されています。

- Shopify の定期購入アプリで自動課金するには、**クレジットカードなど、保存して自動で請求できる決済**が必要です。代金引換・郵便振替では自動課金できません。
- 選択肢：
  1. **カード決済の定期購入に移行**（毎週／隔週／月1 を選択、マイページでスキップ・停止） … 手間が最も減る
  2. **当面は今の運用を継続**（申込フォーム＋振替）し、新規の方からカード定期を案内
- 出荷曜日（月・水・金）の指定やお届け時間帯の指定は、日時指定アプリや商品のオプション入力で対応します。

## 5. まとめ（おすすめ構成）

1. 顧客アカウントを「新しい顧客アカウント」で有効化
2. 定期宅配は Shopify Subscriptions（無料）＋カード決済で開始し、マイページで管理
3. Shopify Flow で定期会員に自動タグ付け
4. テーマに「会員専用ページ」テンプレートを1つ作成（定期会員向けのお知らせ・今週のお野菜）
5. 既存会員は CSV で移行（パスワード再設定は不要）

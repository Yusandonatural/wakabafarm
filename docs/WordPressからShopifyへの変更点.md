# WordPress（旧サイト）から Shopify（新サイト）への主な変更点

旧サイト：WordPress ＋ Welcart（EC プラグイン）＋ 独自テーマ「wakaba」／自社でサーバー契約
新サイト：Shopify（ベーシックプラン想定）＋ Shopify テーマ

## 1. 全体の仕組み

| 項目 | 旧（WordPress） | 新（Shopify） | 変わること |
| --- | --- | --- | --- |
| サーバー・保守 | レンタルサーバー＋WordPress・プラグインの更新が必要 | Shopify が管理（更新・セキュリティ・バックアップ不要） | サーバー代・保守作業が不要に。月額は Shopify 利用料＋決済手数料 |
| デザイン | 制作会社の独自テーマ（PHP） | Shopify テーマ（管理画面のテーマエディタで編集） | 文字・写真・並び順をコードなしで変更できる。独自の装飾は Liquid でカスタマイズ |
| 管理画面 | WordPress 管理画面 | Shopify 管理画面＋スマホアプリ | 注文・在庫・顧客をスマホで管理できる |
| セキュリティ | プラグインの脆弱性・お問い合わせスパム対策（Cloudflare Turnstile）を自前で | Shopify 側で対応、SSL 標準 | 旧サイトで出ていた PHP 警告のような表示崩れがなくなる |

## 2. ネットショップ機能

| 項目 | 旧（Welcart） | 新（Shopify） |
| --- | --- | --- |
| 商品登録 | 投稿＋SKU 設定 | 商品＋バリエーション（今回 CSV で25商品を下書き登録できる状態） |
| 在庫 | SKU ごとの在庫状態（「在庫有り」等の表示） | 在庫数を管理、0 になると自動で「売り切れ」表示 → **SOLD OUT 入りの画像は不要** |
| 決済 | 代金引換のみ（カードは停止中）、定期は郵便局自動振込 | Shopify Payments（カード・Apple Pay・Google Pay・コンビニ等）＋手動決済で「代金引換」「銀行振込」も設定可 |
| 送料 | 地域別送料、クール便＋440円、5,000円以上無料 | 「配送と配達」で地域別送料・送料無料条件を設定。クール便は配送プロファイルを分けて設定 |
| お届け日時指定 | フォームで指定 | 日時指定アプリで対応（カート・チェックアウトで選択） |
| 定期宅配 | 独自フォーム＋手作業で管理 | 定期購入アプリでマイページから変更・スキップ（カード決済が前提）※詳細は「会員機能について.md」 |
| 会員 | Welcart 会員（ID・パスワード） | 顧客アカウント（パスワード不要のコードログイン可） |
| 関連商品表示 | YARPP プラグイン | テーマ標準の「おすすめ商品」 |
| 商品レビュー | 記事（reviewtag）で掲載 | レビューアプリ（Judge.me 等）で商品ページに表示。既存の声は記事として移行も可 |
| 特定商取引法表記 | ショッピングガイドに会社情報 | 管理画面「ポリシー」に特定商取引法表記・返金・配送・プライバシーポリシーを登録（チェックアウトに自動リンク） |

## 3. ページ・記事

| 旧 | 新 | 備考 |
| --- | --- | --- |
| 固定ページ（若葉農園とは、定期宅配、ガイド等） | Shopify の「ページ」 | 文章は `data/pages/*.md` から流用。見出し文字が画像になっている部分はテキストで作り直す |
| 新着情報（7カテゴリ・1,482記事） | Shopify の「ブログ」 | カテゴリはブログを分ける or タグで表現。「お野菜ラインナップ」1,078件は全件移行しない方向を推奨 |
| お問い合わせ（Contact Form 7＋確認画面） | テーマ標準のお問い合わせフォーム | 研修申込など項目が多いフォームはフォームアプリで |
| story.pdf | 「ファイル」にアップロードしてリンク | |

## 4. URL・SEO

- 旧 URL：`/archives/13/`（商品）、`/topics/日本語タイトル/`（記事）、`/about/` など
- 新 URL：`/products/sudachi-ponzu`、`/blogs/news/記事ハンドル`、`/pages/about` の形式に変わる
- **旧 URL → 新 URL の 301 リダイレクト**を Shopify に登録して、検索順位と外部リンク（Instagram・Facebook のリンク等）を引き継ぐ
- 日本語・絵文字入りの記事 URL は英数字に付け替える

## 5. 移行時に作り直す・確認するもの

- **画像**：デザイン素材（ロゴ・見出し画像・アイコン）は著作権を確認して新規制作。商品画像は 500px 四方のものが多く小さいため、元データの入手か新規撮影を推奨（`data/audit/移行前チェック一覧.xlsx`）
- **文章**：誤字・表示ルール（「無農薬」表示、効能表現、グルテンフリー表記など）を修正してから流用（同上）
- **公開ページからは取れないデータ**：顧客、注文履歴、定期契約者、在庫数、下書き商品 → WordPress 管理画面からの出力が必要
- **ドメイン**：wakaba.jpn.com を Shopify に接続するか、新ドメイン（wakabafarm.com）に移行してリダイレクト

## 6. 運用で変わること

- 新着情報の投稿：WordPress → Shopify の「ブログ記事」から投稿（スマホアプリからも可）
- Instagram の投稿をそのまま貼る運用は、Facebook 画像のリンク切れや不可視文字の原因になっていたため、新サイトでは写真をアップロードして投稿するか、Instagram フィード表示アプリで自動表示する
- 注文が入ると Shopify から通知。ヤマト運輸の送り状発行はアプリ連携で効率化できる

# 若葉農園 新サイト（Shopify）移行用データ

旧サイト **https://www.wakaba.jpn.com**（WordPress ＋ Welcart）から、Shopify で新サイトを構築するための
文章・商品・記事・画像を取得し、引き継ぎ用に整理したリポジトリです。

- 取得日: 2026-11-11
- 方針: **文章は原則そのまま流用**／**画像は著作権を確認したうえで、必要なものは新規に撮影・制作して差し替え**

---

## 1. フォルダ構成

```
data/
├── pages/                         固定ページ（各ページ .md = 読みやすい文章 / .html = 元の本文HTML）
│   ├── home.md                    トップページ
│   ├── about.md                   若葉農園とは（会社概要・成分分析表・お客様の声を含む）
│   ├── delivery.md                定期宅配（料金・送料表・申込フォームの項目）
│   ├── guide.md                   ショッピングガイド（支払・送料・返品・お届け日）
│   ├── inquiry.md                 お問い合わせ（フォーム項目）
│   ├── shops.md                   商品一覧
│   ├── topics.md                  新着情報一覧
│   ├── company.md                 会社概要（旧サイトでは中身なし。about.md 下部に記載あり）
│   └── pages.json                 上記をまとめたデータ
├── products/
│   ├── products.json              全商品の詳細（価格・SKU・原材料・内容量・画像・説明文）
│   └── shopify_products_import.csv  ★ Shopify 管理画面「商品 > インポート」でそのまま取り込める CSV
├── topics/
│   ├── topics_index.csv           全記事の一覧（日付・カテゴリ・タイトル・画像数・URL）
│   ├── topics.json                全記事の本文（HTML / テキスト）
│   └── markdown/                  1記事 = 1ファイル（YYYY-MM-DD_記事ID.md）
├── images/                        画像の原寸ファイル（旧サイトのパス構成のまま）
│   ├── uploads/                   投稿・商品で使われている写真
│   └── themes/                    サイトデザイン用の素材（ロゴ・見出し画像・アイコン等）
└── images_manifest.csv            ★ 全画像の台帳（使用箇所・alt・著作権確認欄・対応方針欄）
scripts/scrape.py                  取得スクリプト（再実行可能）
```

## 5. 商品 CSV（`shopify_products_import.csv`）について

- 全商品を **下書き（Status=draft, Published=FALSE）** で作成する設定です。確認後に公開してください。
- 説明文 = キャッチコピー＋説明＋原材料/内容量の表＋詳細本文。
- `Image Src` は **旧サイトの画像 URL** を指しています。インポート時に Shopify が画像を取り込みます。
  - 画像を新しく作る場合は、インポート前にこの列を空にするか、新画像の URL に差し替えてください。
  - 旧サイトを閉鎖した後は URL から取り込めなくなるため、**閉鎖前にインポート**するか `data/images/` のファイルを手動アップロードしてください。
- 在庫数・重量・商品タイプ・タグは旧サイトの公開ページから取得できないため空欄です（後述）。

## 6. 画像の扱い（著作権の確認と再作成）

`data/images_manifest.csv` を台帳として使ってください。各行が1枚の画像です。

| 列 | 内容 |
| --- | --- |
| original_url / local_file | 旧サイトの URL と、ダウンロード済みファイルの場所 |
| used_on_count / used_on | その画像が使われているページ数とページ URL |
| alt | 旧サイトでの代替テキスト（画像の内容のヒント） |
| 区分 | サイト共通（デザイン素材）／商品／固定ページ／記事 |
| **著作権確認** | 自社撮影／外部提供／不明 を記入 |
| **対応方針** | そのまま使用／新規撮影／新規制作／不要 を記入 |
| メモ | 自由記入 |

**判断の目安**
- **デザイン素材（`themes/`：ロゴ、見出し文字画像、アイコン、背景）** … 旧サイト制作会社が作成した可能性が高く、制作会社との契約で権利が移転していない場合があります。ロゴは自社所有か確認、それ以外は新テーマに合わせて **新規制作を推奨**。見出し文字画像（`p_about_main1_ttl.png` 等）は文字情報のため Shopify ではテキストで再現できます。
- **商品写真** … 自社撮影なら継続利用可。制作会社・カメラマン撮影なら利用範囲を確認。新サイトの印象を揃えるなら **新規撮影を推奨**。
- **記事内の写真（スタッフ投稿・LINE アルバム等）** … 多くは自社スタッフ撮影と思われ、そのまま使用できる可能性が高いです。人物が写る写真は掲載同意を確認してください。
- **外部のチラシ・イベント告知画像**（例：百貨店出店告知） … 主催者の素材が含まれる場合は再掲載の可否を確認。

## 7. 公開ページから取得できなかったもの（旧サイト管理者側での出力が必要）

以下は WordPress 管理画面（または サーバー）にログインできる方からの提供が必要です。

- **顧客（会員）データ**：Welcart の会員一覧 CSV → Shopify 顧客インポート（同意取得済みの方のみ）
- **注文履歴・定期宅配の契約者一覧**
- **在庫数・商品の重量・非公開／下書きの商品**
- **レビュー（reviewtag）**：公開されている分は記事として取得済み。専用レビュー機能へ移す場合は別途
- **お問い合わせフォームの送信先メールアドレス**
- **WordPress のエクスポートファイル（WXR）**：念のためのバックアップとして推奨
- **ドメイン・DNS の管理情報**：wakaba.jpn.com を Shopify に向ける際に必要

## 8. 旧 URL からのリダイレクト（SEO 引き継ぎ）

公開後、Shopify「ナビゲーション > URL リダイレクト」で旧 URL を新 URL に転送してください。
旧 URL の一覧は `topics_index.csv`（記事）、`products.json` の `url`（商品）、`pages.json`（固定ページ）にあります。
新ハンドル確定後、リダイレクト用 CSV を生成できます。

## 9. 再取得

```bash
pip install requests beautifulsoup4 markdownify
python3 scripts/scrape.py --images
```

取得した HTML は `.cache/`（Git 管理外）に保存され、再実行時は旧サーバーにアクセスしません。最新状態を取り直す場合は `.cache/` を削除してから実行してください。
